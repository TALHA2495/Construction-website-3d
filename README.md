# Stonehaven Construction — Agentic Project Starter

This folder contains the small set of project instructions and reference assets for building the Stonehaven Construction concept website.

## Start here

1. Open this folder (or merge its contents into your existing website repository) in your coding agent.
2. Read `AGENTS.md` first.
3. Read `design.md` for visual direction and `prd.md` for requirements and acceptance criteria.
4. Follow `.agents/skills/threejs-helix/SKILL.md` when implementing the 3D helix.
5. Keep `LEARNINGS.md` updated with verified findings, real bugs, and decisions that should persist across future tasks.
6. Use the reference images in `assets/reference/` as the supplied desktop and mobile hero image sources.

## Included files

- `AGENTS.md` — global coding-agent behavior and project constraints.
- `design.md` — visual system, typography, responsive rules, and motion principles.
- `prd.md` — product scope, site structure, business workflow, and acceptance criteria.
- `.agents/skills/threejs-helix/SKILL.md` — focused instructions for integrating and validating the reference helix.
- `LEARNINGS.md` — persistent, evidence-based engineering notes.
- `assets/reference/hero-desktop.jpg` — supplied landscape architectural reference.
- `assets/reference/hero-mobile.jpg` — supplied portrait architectural reference.
- `assets/reference/README.md` — image usage and reference notes.

## Project assumptions

- Brand: `STONEHAVEN CONSTRUCTION` (fictional concept brand; replace as needed).
- Initial implementation preference: plain HTML, CSS, JavaScript, and Three.js for a fresh project. If this starter is merged into an existing app, inspect and preserve its existing stack unless a documented reason requires changing it.
